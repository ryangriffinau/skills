# Learnings ledger

Store project-specific rules outside the installed skill, in a location the user
chooses or an existing project communication profile. A practical default is
`docs/project-update-learnings.md`.

Append a rule only after comparing a draft with the version actually sent:

```markdown
## YYYY-MM-DD — short context

- Draft: <relevant wording or structure>
- Sent: <what changed>
- Rule: <reusable instruction for future updates>
- Scope: customer | public-changelog | internal | all
```

A useful rule predicts a future edit. Record “customer asks lead and name the
exact card or access action”; do not record a one-off amount, URL or person's
name. Treat deletions caused by changed facts as case-specific, not voice rules.
